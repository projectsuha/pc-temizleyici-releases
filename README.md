# PC Temizleyici

Windows için temizlik ve bakım aracı. Bu depo yalnızca indirme dosyalarını barındırır.

## İndirme

[Son sürümü indirin](https://github.com/projectsuha/pc-temizleyici-releases/releases/latest)

- **PCTemizleyici-Kurulum-X.Y.exe**: Kurulum sihirbazı (önerilen). Eski sürümün üzerine kurulur, ayarlar korunur.
- **PCTemizleyici.exe**: Kurulum gerektirmeyen tek dosya.

Program açılışta bu depodaki son sürümü kontrol eder ve yeni sürüm varsa haber verir.

> Dosya dijital olarak imzalı olmadığı için Windows ilk açılışta "Windows bilgisayarınızı korudu" uyarısı gösterebilir: **Ek bilgi → Yine de çalıştır**.

## Özellikler

- Geçici dosya, tarayıcı ve sistem temizliği, gizlilik temizliği
- Disk analizi, büyük dosyalar, yinelenen dosyalar ve boş klasörler
- Başlangıç programları, program kaldırma ve winget ile program güncelleme
- Disk sağlığı, ağ araçları, planlı temizlik ve temizlik raporu
- Türkçe ve İngilizce arayüz
